# Reviews

Five deep passes over the tree, each looking at one thing, each defect fixed with
a test that failed against the code before the fix. The failing runs happened in
this sandbox; the fixes are in the commits that follow.

## 1. The toolchain flow

**Cycle guard was ineffective.** `sh_toolchain_ensure` was recursive and marked a
toolchain in-progress only *after* its requirements, so `a` requires `b` requires
`a` recursed forever. Fixed by resolving the requirement order iteratively
(Kahn's algorithm) and refusing a cycle by name. `tests/toolchain.sh` bounds the
case with `timeout` and asserts the refusal.

**Recursion clobbered the parent.** The same function reused global locals, so
the nested call for a requirement overwrote `sh_te_name`; the parent then probed
and installed the *requirement* again and never installed itself. Measured with
`c` requires `d`: `d` installed and adopted twice, `c` untouched, exit 0. Fixed
by splitting a non-recursive `sh_toolchain_install_one` from the order resolver.

## 2. Portability and hidden dependencies

- `bootstrap.sh --list-toolchains` used `tr`, which minimal images (Photon,
  openSUSE) lack. Replaced with a loop.
- `sh_space_gc` assumed `find`; it now clears the named staging areas and, for
  the temp area, says out loud that it is leaving it alone rather than deleting a
  running bootstrap's work.
- `sh_promote_tree` and `sh_fetch_unpack` wrote their queues into `$SH_HOME_TMP`
  with no fallback, so an unset root wrote to `/.promote.$$`. Both fall back to
  `$TMPDIR` / `/tmp`.

## 3. The fetch path and generated files

- `sh_sq_quote` was added and every path written into `env.sh` / `profile.sh`
  goes through it: a home with a space or an apostrophe otherwise produced a file
  that did not read back. Pinned in `tests/unit.sh` through the generated bytes.
- `sh_first_line` / `sh_first_word` tested `read`'s exit status. `read` returns
  non-zero at EOF without a newline, so both answered nothing while the command
  ran. This is what broke Go's version lookup. Pinned with no-trailing-newline
  cases.
- The digest sources were wrong or absent: `nodejs.org/dist/latest/` names a
  train and not a version, and `https://go.dev/dl/<file>.sha256` is an HTML page.
  Node now reads `index.json` and Go reads `dl/?mode=json` by filename, each with
  a `SANDHOME_*_URL` override so the parser is tested against a local file.

## 4. Idempotency and real binaries

- **A fresh shell re-downloaded an installed toolchain.** A toolchain reached
  only through its own PATH fragment (go, rust, uv) is invisible until the
  fragment is sourced, and the probe ran first. `sh_toolchain_install_one` now
  loads the environment before probing. Pinned in `tests/toolchain.sh`.
- **`npm` was broken by the mirror.** A symlinked executable was dereferenced and
  copied under the link's basename, so `bin/npm`'s relative `require` missed its
  package. The mirror now reproduces the symlink and copies the script at its own
  path. Verified against the real `npm` 11.19.1 from the node v26.10.0 tarball.
- **`go run` failed after a successful compile.** `GOCACHE` was on the noexec
  home and `go run` execs what it builds. It is now on `SANDHOME_EXEC`. Verified
  with `go run` and `go test` on Go 1.27.1.
- **Adopted toolchains were pointed at an empty root.** `tc_node_env` and
  `tc_go_env` wrote install-specific configuration even when a system toolchain
  had been adopted, which would break it. Both now return early.

## 5. Documentation, the report, and honesty

- The mirror rule, the exec-only cache rule, the URL overrides and the new
  failure modes are in `docs/guide.md` and `docs/decisions/`.
- `--dry-run` reported `shims=fakepty fakepwd` without compiling anything. A
  report is read from the machine, never from intent; a dry run now names no
  built shim. Pinned in `tests/bootstrap.sh`.
- `sandhome doctor` printed its failures and exited 0. It now exits non-zero.
  Pinned in `tests/bootstrap.sh`.

## What was executed, and what was not

Executed end to end in this sandbox: `jq`, `node` (with `npm`/`npx`), `go`
(build, run, test, vet), and the promoted-symlink and passthrough cases in
`tests/`. Not executed here: `python`, `rust`, `ripgrep`, `fd` were not
re-downloaded in this pass; they are covered by the syntax and framework tests
and by the earlier handoff runs. The full suite is `sh tests/run.sh`.
